# Competitive and reference review

Reviewed 2026-07-26. References are used as loose inspiration, not as recreation targets.

| Reference | Useful pattern | Bindery decision |

## Opportunity

The practical gap is not another event listing. It is a structured edition archive that helps a solo goods creator decide whether to apply and how to prepare:

1. compare application method, documents, business-registration requirement, booth fee, dates, and onsite logistics in the same fields;
2. make deadlines, bookmarks, ICS, and official source checks the primary interaction;
3. show edition history and verification dates so accumulated data becomes more valuable;
4. publish structured feedback only when the N≥5 privacy gate is met;
5. keep Groupbuy informational until policy, approval, reporting, and dispute boundaries are reviewed.
