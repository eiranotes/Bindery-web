# 2026-08-05 international stationery event candidates

This batch contains only editions found on organizer, venue, trade-association,
or public trade-show authority pages for Japan, Taiwan, and mainland China.
Search snippets and third-party calendars were used only for discovery and are
not stored as field evidence.

- Scope: stationery, paper goods, creative goods, and gift fairs with an
  explicit stationery category.
- Snapshot date: 2026-08-05.
- Unknown exhibitor deadlines, selection rules, booth prices, and operations
  remain null.
- A reachable official page plus explicit event dates is the minimum boundary
  for `source_checked` publication. It is not an editor-complete claim.
- The Yiwu stationery fair was excluded because the current organizer page
  still displayed the 2025 edition while search results claimed 2026 dates.
- Design Festa vol.64 is included as a broad creator-goods event rather than a
  stationery-only fair. Its official event, exhibitor, policy, and venue pages
  explicitly support the stored dates, scale, application rules, fees, and
  address.

Run `npm run content:candidates:check-sources` for a live URL audit, followed by
`npm run content:normalize` and `npm run content:generate`.
